# Design references

The Experience redesign references show desktop, tablet (768px), and mobile
(390px) layouts. The mobile image shows two consecutive scroll segments side by
side. They are design references rather than screenshots of the implementation;
use the page source for current copy and behavior. The viewport widths describe
the intended layouts, not the PNG dimensions.

| Experience reference | Use |
| --- | --- |
| [Desktop](experience-redesign/desktop.png) | Full-width cards and a distinct concurrent-contract branch. |
| [Tablet](experience-redesign/tablet.png) | Single-column timeline with a narrow rail. |
| [Mobile](experience-redesign/mobile.png) | Narrow-screen card hierarchy and text preview controls. |
